# Laboratorio 2 - HTML5

Este repositorio contiene los ejercicios realizados durante el segundo laboratorio, enfocado principalmente en el uso de **HTML5** y algunos conceptos básicos de **CSS**.

La idea del laboratorio es practicar la estructura de una página web y aprender a utilizar diferentes elementos de HTML, como párrafos, tablas, secciones y validaciones.

## ¿Qué hay en el repositorio?

Entre los ejercicios realizados se encuentran:

* Ejemplos de estructura básica de HTML5.
* Uso de párrafos y diferentes elementos de texto.
* Creación y organización de tablas.
* Uso de secciones dentro de una página.
* Validaciones de HTML5.
* Aplicación de estilos básicos con CSS.
* Ejemplos de HTML junto con PHP.

## Archivos principales

* `Ejemplo1.html` — Ejemplo básico de HTML.
* `EjemploSecciones.php` — Ejemplo utilizando diferentes secciones.
* `ValidacionesHTML5.html` — Ejemplos de validaciones de HTML5.
* `parrafos.html` — Ejercicios relacionados con párrafos.
* `tablas.html` — Ejemplo de creación de tablas.
* `tablas2.html` — Segundo ejercicio con tablas.
* `estilosParrafos.css` — Estilos utilizados para los párrafos.
* `estilosTabla.css` — Estilos utilizados para las tablas.

## ¿Qué se utilizó?

* HTML5
* CSS
* PHP
* Visual Studio Code

## ¿Cómo ejecutarlo?

Los archivos `.html` se pueden abrir directamente desde el navegador.

Para los archivos `.php`, se puede utilizar un servidor local como **WAMP**.

Si se utiliza WAMP, se coloca la carpeta del proyecto dentro de:

```text
C:\wamp64\www\
```

Luego se inicia WAMP y se puede acceder al proyecto desde:

```text
http://localhost/Laboratorio-2-HTML-5/
```

## Objetivo

El objetivo de este laboratorio es practicar los conceptos básicos de **HTML5**, aprender a estructurar páginas correctamente y comenzar a utilizar CSS para darles un poco de estilo.
